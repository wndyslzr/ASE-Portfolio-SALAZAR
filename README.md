# ASE-Portfolio-SALAZAR

## Course Introduction
This repository serves as my individual portfolio for **CPELX230-33** (Term 2, 2026-2027) under the Computer Engineering Department, College of Engineering at National University. The course explores **Agentic Software Engineering and Responsible AI**, bridging foundational software engineering principles, Agile/Scrum methodologies, and Git version control with modern intelligent agent design and AI risk governance frameworks.

## Personal Learning Goals
* **Understand Agentic Architectures:** Design and implement AI-driven systems that can perceive inputs, plan tasks, and interact with external tools reliably.
* **Apply Agile and Version Control Practices:** Use Git workflows and iterative Scrum principles to manage evolving requirements, track changes cleanly, and collaborate effectively.
* **Prioritize Security and Responsible AI:** Apply the NIST AI Risk Management Framework to identify, mitigate, and govern risks such as prompt injection, data leakage, hallucinations, and bias.
* **Build Real-World Engineering Competence:** Translate theoretical AI and software concepts into safe, maintainable, and human-supervised applications.

## Reflection from Part A
Analyzing the foundations of Agentic Software Engineering highlighted a key shift in modern development: building autonomous systems is no longer just about writing deterministic logic, but about managing probabilistic behavior safely. While AI agents offer adaptability and reasoning beyond traditional applications, their autonomy introduces significant security, reliability, and governance challenges. Pairing iterative Agile processes with disciplined version control and human-in-the-loop oversight is essential to ensure agentic systems remain predictable, accountable, and aligned with user needs.
